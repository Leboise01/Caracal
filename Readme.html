À propos de ce site

introduction


Bienvenue sur le site internet de la patrouille du caracal.

Le projet de ce site a commencé à ma deuxième année, en 2024-2025, pour la patrouille du caracal, dans le but d'obtenir le badge informatique.
J'ai alors commencé à le construire, et les deux premières version du site ont étées entièrement tapées à la main, en environ 1000 ligne de code pour l'entièreté de la structure.
Le but a toujours été de présenter les photos et le calendrier de l'année
Ce site, dans ses premières version, était purement en html, le code des pages web, avec une couche de css pour le style, les couleurs et les polices.
Je me suis toujours basé sur des services gratuits qui hébergent les pages, contre leur nom dans l'url du site.
Ici Render.

Vous avez sans doute remarqué que cette version du blog est d'une qualité largement supérieure aux autres, de par sa structure, ses options et son style.
J'ai choisi, après deux ans de développement d'un site très basique, de m'appuyer sur de nouveaux outils pour obtenir une qualité meilleure, mais en perdant le mérite de tout faire soi-même.

En effet, le style de ce site a été imaginé par lovable.dev sur la base de ma structure et de mon code. Cet outil a créé des milliers de fichiers inutilisables par l'humain, et j'ai passé plusieurs heures, avec l'aide de cursor, à le réduire en simples fichiers html, que j'ai ensuite modifiés à ma manière.

Au quotidien, j'utilise l'agent de Visual Studio Code, mon éditeur de code personnel, pour automatiser les tâches.

Ce site m'a donné plusieurs dizaines d'heures de travail, et je suis désormais très fier de vous l'avoir rendu beau, pratique et accessible.

Ambroise Uyttenhove
